Reviewed 21 October 2026. Repository-derived measurements are the already executed CPU studies. New NPU performance, memory capacity, topology and biological validation remain UNKNOWN. Proposed thresholds, model shapes and resource budgets are this project's design decisions rather than vendor or dataset claims.

## Retrieval and version notes

Some NCBI HTML pages and publisher pages returned limited or error responses through the web reader. Official SOFT text for S08/S09 was successfully retrieved using NCBI's standard text view. The Ascend compatibility source was also retrieved directly, and the upstream master revision was resolved to `e8c7f12c5b371dfd46e919d7d6ad190dd53d4b51`; final checks authenticate the candidate against that immutable revision. No access controls, login wall or CAPTCHA were bypassed.

Before implementation, archive the applicable vendor matrix and each dataset's metadata/terms with retrieval time and hash. Resolve package wheel ABI, OS, actual product, driver/firmware and data-file hashes against the selected host/source. A successful metadata read does not certify the whole dataset or confer a new commercial license. Public data and pretrained models retain their original rights and attribution.

This register separates source facts from planning judgments. Model parameter targets, compute ceilings, sampling ladders, statistical gates and the proposed division of work between B/C pools are engineering proposals. Runtime and biological outcomes require new evidence.
